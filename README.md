# onto.travel listings & hotel page — UI prototype

Clickable prototype of the hotel listings (PLP) and hotel detail (PDP) pages, with dummy data. No backend.

Live: https://ramshid-onto.github.io/onto-prototype/

- Layout switcher at the bottom of the page (listings: Classic / List / Gallery; hotel page: room layouts A–E).
- Click any hotel card to open its hotel page.

`index.html` is generated from the source in the private `web` repo (`listings/build.py`); edit there, not here.
